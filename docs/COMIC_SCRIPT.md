# Notice Period: comic script, Issues #1–#5 (draft v1, 22 Nov 2026)

## How to read this script
- **PAGE** = one phone screen (2–4 panels, read top to bottom). **SPLASH** = one full-screen panel.
- **PANEL** lines describe the art. Then:
  - `CAPTION:` the yellow narrator box
  - `NAME:` a speech balloon
  - `NAME (thought):` a thought bubble
  - `SFX:` sound-effect lettering
  - `CAMERA:` how the panel moves (pan, zoom, shake)
- `{HERO}` = the name the player types at the start. The hero is "they" in descriptions.
- **CHOICE** = a tappable panel that nudges the meters. **LEVEL** = the comic hands over to a mini game.
- **Meters:** 💼 Job Hunt (starts 0) · 🎯 Blame (starts 10/100) · 🔋 Sanity (starts 7/10).
- Every level has 3 result variants: ★★★ / ★–★★ / no stars. The comic continues either way; only the meters differ.
- All names (Synergex Solutions, SynChat, SynergexOne, Brightline Labs) are fictional.
